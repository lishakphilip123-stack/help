# 🆘 Emergency Response FAQ Chatbot

AI Friday Season 2 — Qualifiers | Team ID: 1940d191-f38e-43bf-bacf-769cac764dac

## Setup & Run

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Start the app
python app.py

# 3. Open in browser
http://localhost:5000
```

## Features
- 6 emergency scenarios: Flood, Fire, Earthquake, Cyclone, Medical, Chemical
- 100 Q&A pairs as grounding context
- GenAI-powered follow-up question support
- Response time displayed per message (target < 5s)
- Quick question sidebar per scenario
- Fallback handling for API errors
